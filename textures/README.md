# Planet images

Images mapped onto the planet sphere by mag3d (equirectangular, width:height = 2:1, top = north pole, center = longitude 0).
With `planet_texture = 'auto'`, `<planet>.jpg` (or .png) is used.

| file | content |
|---|---|
| earth.jpg | Natural Earth I (public domain, https://www.naturalearthdata.com/) resized to 1024×512 |
| jupiter.jpg | schematic image of the bands and the Great Red Spot (generated by `make_textures.py`; not a real image) |
| saturn.jpg | schematic image of the bands (generated by `make_textures.py`; not a real image) |

To use real images, replace these files with images of the same names, or give a file name in `planet_texture` of the namelist.
